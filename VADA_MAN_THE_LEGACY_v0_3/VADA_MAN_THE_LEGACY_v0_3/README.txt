VADA MAN: THE LEGACY — VERSION 0.3
=====================================

QUICK PREVIEW
1. Extract the ZIP.
2. Keep the assets folder beside index.html.
3. Double-click index.html to open it in Chrome.

WHAT'S INCLUDED
- Custom hero using your Vada Man character artwork.
- Your VADA MAN: THE LEGACY logo.
- Hybrid cinematic / comic-book visual design.
- Responsive desktop and mobile layout.
- Expandable character dossiers.
- Eight episode placeholders.
- All 17 soundtrack tracks in the exact order supplied.
- Individual YouTube links for all 17 tracks.
- Embedded YouTube playlist player.
- Fictionalised character framing; no additional real identities exposed.

PUBLISHING TODAY
The ZIP is a static website and can be hosted without a backend.
A straightforward option:
1. Create/sign in to a GitHub account.
2. Create a new public repository (e.g. vada-man-the-legacy).
3. Upload index.html and the entire assets folder to the repository root.
4. Open Settings > Pages.
5. Under Build and deployment, choose Deploy from a branch.
6. Select main and /(root), then Save.
7. GitHub will provide the public website URL after deployment.

Before publishing:
- Check that you have permission to publish the character artwork and music.
- Verify the listed music credit and any third-party names.
- Test the site on a phone and desktop.
- YouTube embeds/links require internet access and may be unavailable for private, removed or region-restricted videos.

EDITING
- All song titles, descriptions and YouTube video IDs are in the `songs` array near the bottom of index.html.
- Keep the assets folder and its filenames unchanged unless you also update the image paths in index.html.
